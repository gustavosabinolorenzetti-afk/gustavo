# 🚀 Central de Códigos - GitHub Pages

Este repositório contém o código-fonte da minha biblioteca online de snippets e algoritmos, hospedada via **GitHub Pages**.

## 🛠️ Como Funciona
- `index.html`: Estrutura do site com seções divididas por temas/linguagens.
- `style.css`: Estilização responsiva em Dark Mode inspirada no design do GitHub.

## 📍 Como Ativar no GitHub Pages
1. Vá em **Settings** no seu repositório.
2. Na aba lateral esquerda, clique em **Pages**.
3. Em **Branch**, selecione `main` (ou `master`) e clique em **Save**.
4. Acesse em: `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`
